How to Play GRIDSEC

1. Follow the 6-Phase Decision Loop

Real control rooms follow a strict cycle: Observe telemetry → Investigate using graph algorithms → Decide the safest intervention → Act → Evaluate physical response → Continue.

2. Manage your Defence Points (DP)

Running algorithms (BFS, Dijkstra, Tarjan) costs 0 DP. Taking irreversible physical actions (Isolating lines, Reclosing breakers, Shedding load) costs DP. Do not act blindly!

3. Watch for False Data Injection Attacks (FDIA)

Adversaries may spoof sensor values to make healthy lines look overloaded. Always run AC Feasibility & Chi-Square Residual Tests before tripping breakers!

4. Real-Time Attacks

Scripted attacks advance across 4 stages. An amber badge gives you 20 seconds to neutralize the intrusion before breakers trip automatically.
